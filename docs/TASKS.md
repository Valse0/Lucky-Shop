# Implementation Checklist

## Audit
- [ ] Identify framework, package manager, entry point and scripts.
- [ ] Identify existing gameplay/economy/save implementation.
- [ ] Inventory both asset ZIPs without modifying originals.
- [ ] Create contact sheets for image assets.
- [ ] Compare candidates against the supplied reference.
- [ ] Report plan and wait for approval.

## Asset Pack
- [ ] Select best symbols and UI pieces from both packages.
- [ ] Repair only where needed.
- [ ] Generate missing assets only if image-generation capability is available.
- [ ] Normalize dimensions/names.
- [ ] Create manifest and asset QA report.

## UI
- [ ] Build portrait responsive layout.
- [ ] Match reference hierarchy and visual language.
- [ ] Use actual independent assets and real text.
- [ ] Verify small-screen fit.

## Game
- [ ] Implement/test 5×3 outcome model.
- [ ] Implement bet/balance validation.
- [ ] Implement paytable and payout tests.
- [ ] Integrate sequential reel animation.
- [ ] Test spin lock, cancellation, reduced motion.

## Progression and QA
- [ ] Shop upgrade and level/XP.
- [ ] Daily bonus with honest local/demo semantics.
- [ ] Missions/rewards/leaderboard screens within current scope.
- [ ] Build/lint/test and final report.
