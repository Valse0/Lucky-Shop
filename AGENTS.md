# Repository Agent Rules — Lucky Shop

- Read `MASTER_PROMPT_TR.md`, `docs/GAME_DESIGN.md`, `docs/ASSET_RULES.md`, and `docs/CHANGELOG_POLICY.md` before implementation.
- Do not overwrite user work or reset Git state.
- Do not change the project's framework or package manager without explicit approval.
- Keep game outcome/economy logic separate from presentation and animation.
- Never use emoji as final slot art.
- Never flatten the reference screenshot into a fake interactive screen.
- Preserve source ZIPs; stage and audit assets before copying.
- Use real text for labels; no text baked into buttons/panels.
- Run the repository's actual build/lint/test scripts after each implementation stage.
- Update `docs/CHANGELOG.md` after each completed stage.
- If a requirement conflicts with the existing architecture, explain the conflict and propose the smallest safe adaptation before coding.
